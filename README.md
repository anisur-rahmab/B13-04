

## Answers to Questions

### 1. Question: What is the difference between getElementById, getElementsByClassName, and querySelector / querySelectorAll?
### 1. Answer: getElementById() = Holds only one element with a specific id,  getElementsByClassName() = Capture all matching element with a class name. and querySelector() = Capture the first matching element with a CSS selector. and querySelectorAll() = Captures all matching elements with a CSS selector.

### 2. Question: How do you create and insert a new element into the DOM?
### 2. Answer: I will create a new element. Add content or attribute to the element. Insert into DOM

### 3. Question: What is Event Bubbling? And how does it work?
### 3. Answer: When an event occurs on an element, it is first triggered by that element, then it goes up step by step to its parent → grandparent → document.

### 4. Question: What is Event Delegation in JavaScript? Why is it useful?
### 4. Answer: Event Delegation is a technique where we place a single event listener on their parent element, rathar than provid a separate event listener on each child element.


### 5. Question: What is the difference between preventDefault() and stopPropagation() methods?
### 5. Answer: preventDefault() Prevents default behavior and stopPropagation() Stops the event bubble.
