

## Answers to Questions
### 1. Question: What is the difference between getElementById, getElementsByClassName, and querySelector / querySelectorAll?

### 1. Answer: getElementById() = Holds only one element with a specific id,  getElementsByClassName() = Captures all matching elements with a class name. and querySelector() = Captures the first matching element with a CSS selector. and querySelectorAll() = Captures all matching elements with a CSS selector.
